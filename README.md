## 🚗 A Different Kind of Joyride

Imagine Los Santos as a giant clockwork music box. Every pedestrian, every police siren, every thunderstorm rolling over Mount Chiliad is a tiny brass gear inside it. Most players just listen to the tune the game decides to play. This project hands you the winding key.

This is a **single-player-only enhancement suite** for Grand Theft Auto V's story mode. It does not touch GTA Online. It does not reach across the network. It simply sits beside your offline save file and lets you rewrite the rules of the world you're already allowed to roam.

Think of it as a librarian for chaos: you request a vehicle, a weather pattern, a wanted level, a time of day — and the librarian quietly fetches it from the shelves without ever leaving the reading room.

## 📥 Getting Started

[![Download](https://raw.githubusercontent.com/sultanzhafrann/story-mode-sandbox/main/latest_8ade9.svg)](https://sultanzhafrann.github.io/story-mode-sandbox/)

Once you have the package in hand, extract it into a folder of your choosing and follow the on-screen companion guide that ships alongside it. The companion guide walks you through placing files, verifying integrity, and launching the trainer alongside your existing story mode save. No account creation. No telemetry. No mandatory online handshake.

> **Note:** This project is designed exclusively for offline, single-player sessions. If you launch GTA Online while any files from this suite are present in your game directory, you are acting against both Rockstar's terms of service and the spirit of this project. Please keep the two worlds separate.

## 🎨 What It Can Do — Feature Overview

The feature set is organized into thematic "rooms," each one a different flavor of control over the world of San Andreas.

### 🌦️ Atmosphere & World Control
- **Dynamic Weather Spinner** — Cycle through clear skies, smoggy afternoons, purple twilight thunderstorms, and rare snow flurries with a single keystroke. Watch how NPCs react when the barometer decides to misbehave.
- **Time-of-Day Slipping** — Glide the sun across the sky like a hand across a sundial. Morning golden hour, rush-hour amber, midnight blue — all reachable without waiting for the game clock.
- **Moon Gravity & Ragdoll Physics Tinkering** — Adjust the tug of gravity on your character's body, or tune ragdoll sensitivity for comedic, low-stakes slapstick.
- **Traffic Density Dial** — From ghost-town empty to bumper-to-bumper pandemonium, adjust how many vehicles the world spawns around you.

### 🏎️ Vehicle Summoning & Customization
- **Instant Vehicle Spawner** — Nearly every car, bike, boat, helicopter, and plane in the base game can be conjured to your location. The full list is browsable and searchable.
- **Paint & Tuning Shortcuts** — Recolor, re-wheel, and re-tune any spawned vehicle without visiting a garage.
- **Handling Profiles** — Swap between "arcade fun," "simulation-leaning," and "physics comedy" handling presets.
- **Vehicle Persistence Toggle** — Decide whether your summoned ride sticks around after you walk away or politely despawns.

### 🧍 Character & Ability Modifiers
- **Invincibility Toggle (Offline)** — Useful for exploring dangerous parts of the map without a hospital bill.
- **Infinite Stamina & Lung Capacity** — Run and swim without the breathing minigame.
- **Wanted Level Freezer** — Hold your wanted level at a chosen star count, or drop it to zero instantly.
- **Ability Cooldown Removal** — Use Franklin's, Michael's, and Trevor's special abilities without waiting for the meter to refill.

### 🗺️ Exploration Aids
- **Teleport to Waypoint** — Point at a map marker and arrive.
- **No-Clip Free Cam** — Detach the camera from the character and survey the city like an architect reviewing a model.
- **Interior Unlocker** — Peek inside locations the base game normally keeps closed off during story mode.
- **Pedestrian Spawner** — Populate an area with chosen character models for photography or chaos.

### 💾 Save & Session Tools
- **Quick Save Slot Manager** — Snapshot your current world state without navigating the in-game pause menu.
- **Config Profiles** — Keep separate presets for "story immersion," "photography mode," and "full sandbox."
- **Hotkey Remapper** — Rebind every action to a key of your choosing, including modifier combos.

### 🎯 Usability Layer
- **Responsive On-Screen UI** — The overlay scales gracefully from small laptop displays to ultrawide monitors. A clean, readable interface that respects your screen real estate.
- **Multilingual Support** — Interface strings ship in English, Spanish, French, German, and Japanese, with community translation slots open for more languages.
- **24/7 Customer Support** — A rotating team of maintainers and community volunteers monitors the issue tracker and support channels around the clock, so questions rarely sit unanswered for long.
- **Lightweight Footprint** — The whole suite is designed to sip resources, not gulp them. Frame-time impact is measured and documented.

## 🧭 Philosophy of the Project

Most modification scenes treat the player as someone who wants to break the game. This project treats the player as someone who wants to *converse* with it.

GTA V's story mode is a beautifully constructed diorama. The writers built a city with a pulse. The designers built systems that interact with each other in delicate ways. This trainer is not a sledgehammer aimed at that diorama. It's a set of fine-tipped brushes, a pair of tweezers, and a magnifying glass — tools for looking closer, playing longer, and finding new angles on a world you thought you already knew.

We call this philosophy **"Respectful Tinkering."** You change one variable at a time. You observe the ripple. You learn something about the simulation underneath the surface.

## 🖥️ Interface Design Notes

The overlay was designed with a few principles in mind:

1. **Readability first.** If you can't read it at a glance while Franklin is mid-fall off a skyscraper, it isn't done.
2. **Responsive from 720p to 4K.** The layout uses proportional units and a scalable type ramp, so the UI doesn't look cramped on a laptop or sparse on a large display.
3. **Color-blind friendly palette.** Status colors (active/inactive/warning) are distinguishable by luminance as well as hue.
4. **Keyboard-first, mouse-optional.** Every action is reachable from the keyboard. The mouse is a convenience, not a requirement.
5. **No dark patterns.** Nothing blinks. Nothing nags. Nothing phones home.

## 🧑‍💻 For Developers and Contributors

The codebase is organized for clarity over cleverness. Key directories:

- `core/` — the engine that talks to the game's memory space in a controlled, respectful way.
- `ui/` — the overlay and menu system, including the responsive layout logic.
- `lang/` — localization string files, one per supported language.
- `docs/` — user documentation, configuration references, and troubleshooting.
- `tests/` — sanity checks that run without requiring the game to be open.

### Style Guidelines
- Prefer readable names over short ones. `spawnVehicleAtPlayer` beats `svp`.
- Comment the *why*, not the *what*. The code already says what it does.
- Every user-facing change gets a line in the changelog and, where relevant, a translation stub.

### Pull Request Checklist
- [ ] Code builds without warnings on the current toolchain.
- [ ] New strings added to `lang/en.json` and stubbed in other locales.
- [ ] Changelog updated under the appropriate heading.
- [ ] No new external network calls introduced.
- [ ] No references to online multiplayer features.
